Frequently asked questions

Still curious? Everything you need to know before you install.

Is BubbleTranslate free?

Yes. The core app is free to download and use on all platforms. Optional premium translation engines may be offered later.

Does it work without internet?

The offline engine handles common language pairs on-device. Cloud engines are optional for the highest accuracy and rare languages.

Which languages are supported?

Over 100 languages, with automatic detection of the source language so you rarely have to set anything.

Will it work over full-screen games?

Yes. The floating overlay is designed to sit on top of games and visual novels so you never have to alt-tab.

Is my screen data sent anywhere?

With the offline engine, captured text never leaves your computer. If you enable a cloud engine, only the selected text is sent for translation.
